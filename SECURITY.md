# Security

Please avoid posting API keys, private selected text, or sensitive logs in a public issue.

For a security report, use GitHub's private vulnerability reporting for this repository when available. Include the macOS version, app version, reproduction steps, and impact; redact credentials and personal content.

UTUVO Explain stores the Gemini API key in macOS Keychain. Selected text is sent to the configured Gemini API only after an explanation or translation is requested.
