# Facebook 發布文案

最近做了一個自己會用的 Mac 小工具：**UTUVO Explain（貓貓翻譯家）** 🐱📖

看英文文章或文件卡住時，選取那段文字，按 **⌥D**，就能看到繁體中文的白話解釋；只想看譯文，按 **⌥⇧D**。小視窗會盡量出現在選字附近，不用一直切換到翻譯網站。遇到抓不到選字的 App，也可以直接貼上文字。

選單列現在還有一隻讀書的橘貓，跟 Paw、Drop 同系列 XD

App 免費、MIT 開源。支援 **macOS 14 以上的 Apple Silicon Mac**，安裝用的 DMG 已通過 Apple 簽章與公證。使用時需要自己的 Gemini API Key；Google 的免費額度與使用規則以官方資訊為準。
