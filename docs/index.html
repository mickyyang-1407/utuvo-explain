03 / YOUR SETUP

你的 Key。
你的節奏。

UTUVO Explain 不要求建立新帳號。你在設定中加入自己的 Gemini API Key，App 只在你觸發解釋或翻譯時，把該段文字送往 Google。免費額度與資料使用規則由 Google 決定。

  • Key 留在 Mac 鑰匙圈不寫進原始碼，也不放進翻譯紀錄。
  • 首次需要 macOS 權限用來取得目前選字並辨識快捷鍵；目標 App 無法提供選字時，可手動貼上。
  • 沒有歷史清單App 不保存解釋與翻譯紀錄；原文送出前請自行確認是否適合交給 Gemini 處理。
GOOD TO KNOW

開始前，先說清楚。

這個 App 完全免費嗎？

App 免費且 MIT 開源。你需要自己的 Gemini API Key；Google 的免費額度、速率限制與資料使用規則可能調整，請以 Google 官方說明為準。

為什麼需要「裝置控制和資料取用」權限？

App 透過 macOS 輔助使用機制取得當下選取的文字，也需要辨識全域快捷鍵。它不會記錄按鍵；如果個別 App 不提供選字，可以直接在 Explain 視窗貼上文字。

支援哪些 Mac？

目前提供 macOS 14 以上、Apple Silicon 的安裝包。原始碼可以自行編譯；Intel Mac 尚未驗證。
