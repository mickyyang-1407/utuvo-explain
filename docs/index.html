03 / 框選螢幕（0.2 新增）

圖片、影片裡的字，
框起來就懂。

字幕、截圖、掃描的 PDF 選不到字？按 ⌥S 框住那一塊，Explain 會在 Mac 本機辨識文字，再解釋或翻譯。

  1. 01

    按 ⌥S，框住字幕

    畫面出現十字指標，拖曳框住要看的字。按空白鍵可以改選整個視窗，按 Esc 取消。想直接看譯文就按 ⌥⇧S。

  2. 02

    放開滑鼠，小視窗馬上出現

    先顯示「正在辨識」，接著出現白話解釋。辨識出的原文會放在上方，有錯字可以按「編輯」修正後再送一次。

  3. 03

    要譯文就切到翻譯

    同一段字可以在視窗裡切換「白話解釋」和「翻譯」，也可以一鍵複製結果。

  4. 04

    第一次使用：允許螢幕錄製

    框選螢幕需要 macOS 的「螢幕與系統錄音」權限。第一次按 ⌥S 時系統會詢問，開啟後重新啟動 App。App 內也有「使用教學」，隨時可以從選單列打開。

文字辨識在你的 Mac 上完成，框選的畫面辨識完就刪除；只有辨識出的文字會送給 Gemini。示意圖中的影片畫面為示範用。

04 / 開始使用

填入自己的
Gemini API Key。

UTUVO Explain 不需要另外註冊帳號。第一次使用時，在設定中貼上自己的 Gemini API Key。只有你按下快捷鍵或功能按鈕，App 才會把那段文字送給 Google 處理。

  • API Key 存在 Mac 鑰匙圈App 呼叫 Gemini 時，才會用這組 Key 驗證身分。
  • 第一次使用要開啟 Mac 權限這項權限用來讀取目前選取的文字，並接收全域快捷鍵。
  • 框選螢幕只在本機辨識截圖不上傳，辨識完就刪除；需要「螢幕與系統錄音」權限。
  • 不儲存使用紀錄App 不會保存翻譯或解釋的歷史。送出前，請先確認文字是否適合交由 Gemini 處理。
常見問題

下載前想知道的事

需要付費嗎？

App 免費，而且以 MIT 授權開源。你需要自己的 Gemini API Key；Google 的免費額度、使用限制和資料使用規則，請以 Google 官方說明為準。

為什麼要開啟 Mac 權限？

App 需要讀取你目前選取的文字，並接收 ⌥D、⌥⇧D 快捷鍵。它不會記錄其他按鍵。如果某個 App 無法提供選字內容，你也可以手動貼上文字。

框選螢幕會把畫面傳出去嗎？

不會。框選的畫面在 Mac 本機用 Apple 的文字辨識讀出來，辨識完立刻刪除；只有辨識出的文字會在你按下後送給 Gemini。這個功能需要「螢幕與系統錄音」權限，只在你按 ⌥S 時使用。

哪些 Mac 可以安裝？

目前提供 macOS 14 以上、Apple Silicon Mac 的安裝包。Intel Mac 尚未驗證。
