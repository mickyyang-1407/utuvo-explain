# UTUVO Explain 教學影片｜發文文案

## 主文（FB／IG／Threads）

看影片、讀 PDF 常卡在一句英文，想查又選不到字？

我把自己的 Mac 小工具「UTUVO Explain・貓貓翻譯家」更新到 0.2 了。
有使用者問能不能加 OCR，所以這版多了「框選螢幕」：

⌥D 選字 → 白話解釋
⌥⇧D 選字 → 只看譯文
⌥S 框住影片字幕、截圖、掃描檔 → 辨識文字再解釋（⌥⇧S 直接翻譯）

文字辨識在 Mac 本機做，框的畫面用完就刪，只有辨識出的文字會送給 Gemini。
App 免費、開源，要自備免費的 Gemini API Key。1 分半的教學影片放在下面，第一次打開 App 也會有內建教學。

下載：https://mickyyang-1407.github.io/utuvo-explain/
（macOS 14 以上、Apple Silicon）
